¿Qué es una base de datos distribuida?

Datos repartidos Están en varios sitios conectados por una red
Un solo sistema El usuario los ve como una sola base
Sitios que cooperan Cada uno funciona por su cuenta y se ayudan entre sí

Propiedades ACID

Atomicidad Se hace todo o no se hace nada
Consistencia La base siempre queda en un estado válido
Aislamiento Dos transacciones a la vez no se estorban
Durabilidad Lo confirmado sobrevive a una falla

Al distribuir una base de datos

Control distribuido Hay un administrador global y cada sitio conserva autonomía local
Fiabilidad y disponibilidad Si un sitio cae, los demás siguen con los datos repetidos
Consultas más rápidas Se dividen en subconsultas en paralelo
